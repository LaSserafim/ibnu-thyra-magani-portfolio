## 🚀 Featured Projects

2. **[The Link Reaction](https://github.com/LaSserafim/the-link-reaction)** — Interactive 8-stage cellular respiration simulation aligned with the Cambridge International A-Level Biology (9700) curriculum.
3. **[FutureAs](https://github.com/LaSserafim/futureas)** — Quantitative stock analytics platform featuring a 1,000-path Geometric Brownian Motion (GBM) Monte Carlo simulator and SEC Form 4 insider transaction tracker.
4. **[Stock Intelligence Cloud](https://github.com/LaSserafim/stock-intelligence-cloud)** — Automated daily equity research pipeline with dual-redundant scheduling (macOS launchd + GitHub Actions) and headless Chromium PDF report generation.
5. **[QUANT.IDX Terminal](https://github.com/LaSserafim/quantidx)** — Indonesian Stock Exchange (IDX) market microstructure analytics terminal with 15-level Depth of Market (DOM) and Order Flow Imbalance (OFI).

## 🛠️ Tech Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4
- **Graphics Engine:** WebGPU custom shader (`WGSL`) with WebGL2 canvas fallback
- **Motion:** GSAP + Framer Motion
- **Icons:** Lucide React + Simple Icons SVG
- **Deployment:** GitHub Pages (automated with GitHub Actions)
